# EyeCare Analytics Dashboard

A portfolio-ready healthcare operations analytics project built around **1,000 synthetic eye-care patient visits**. The project examines patient volume, department demand, appointment outcomes, waiting times, revenue, payment methods and patient satisfaction.

> **Data notice:** All records generated by this project are fictional and synthetic. They do not represent real patients, a real hospital, or actual hospital revenue. Do not use this dataset for clinical decisions.

## Project objectives

- Understand patient visit patterns across departments and branches.
- Measure appointment completion, cancellation and no-show rates.
- Identify departments with high patient demand and long waiting times.
- Analyze billed fees and collected revenue by department, branch and payment method.
- Explore patient satisfaction and its relationship with waiting time.
- Present operational findings in a clear dashboard.

## Reproduce the project

### 1. Set up Python

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
```

### 2. Generate the synthetic dataset

```bash
python python/generate_dataset.py
```

This creates `data/eye_hospital_1000_synthetic_patient_records.csv` with exactly 1,000 rows and a fixed random seed for reproducibility.

### 3. Run exploratory data analysis

```bash
python python/eda_analysis.py
```

The script validates the dataset, prints key metrics and saves chart images under `outputs/eda/`.

### 4. Run SQL analysis

Open a SQLite database and execute `sql/01_create_tables.sql`, import the generated CSV into the `patient_visits` table (or use your database's CSV import feature), then run `sql/02_analysis_queries.sql`.

### 5. Build the spreadsheet dashboard

Open the CSV in LibreOffice Calc. Create the six PivotTables described in [Dashboard Guide](docs/DASHBOARD_GUIDE.md), then build KPI cards and charts from the pivot results.

### 6. Build the Power BI dashboard

Import the CSV into Power BI Desktop, verify data types, create the measures in [Dashboard Guide](docs/DASHBOARD_GUIDE.md), and arrange the visuals as described there.

## Core business questions

1. Which departments and branches receive the highest number of visits?
2. What proportion of appointments are completed, cancelled or marked no-show?
3. Which departments have the longest average waiting time?
4. Which departments and branches generate the highest billed fees?
5. Which payment methods are most frequently used?
6. How do satisfaction ratings vary across waiting-time bands?

## Metric definitions

- **Total visits:** Count of visit records.
- **Completed visits:** Count of records with appointment status `Completed`.
- **Completion rate:** Completed visits / total visits.
- **Average waiting time:** Arithmetic mean of waiting time in minutes.
- **Total billed fees:** Sum of the synthetic consultation/service fee field across records. This is not audited or actual collected revenue.
- **Average satisfaction:** Mean of the 1–5 satisfaction score, excluding blank values.

## Important analytical limitations

- The data is synthetic and designed for portfolio demonstration.
- The dataset is cross-sectional visit-level data; repeated visits by a patient may occur.
- Relationships in the data are illustrative, not causal.
- Fees are synthetic billed amounts. They should not be described as real hospital revenue.
- No clinical diagnosis, treatment outcome or personally identifiable patient data is included.

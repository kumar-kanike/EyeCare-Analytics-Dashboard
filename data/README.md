# Data

Run `python python/generate_dataset.py` from the repository root to generate:

`eye_hospital_1000_synthetic_patient_records.csv`

The output contains 1,000 synthetic visit-level records. It is intentionally generated locally rather than committing a potentially misleading dataset as if it were real hospital data.

All names, phone-like values, dates, departments, doctors, fees and ratings are fictional. The data is for analytics practice only.
